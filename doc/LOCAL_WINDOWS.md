# Windows 로컬 번역판

일본어 만화를 한국어로 번역하는 개인용 구성입니다. 기본 구성은 CTD(대사 영역 검출), manga_ocr(일본어 인식), LaMa(원문 제거), Ollama의 Qwen3.5 9B Q4_K_M(한국어 번역)입니다. 모델마다 선택하는 복잡한 설치 절차 대신 준비 화면에서 필요한 구성만 설치합니다. 실제 만화 번역의 최상위 품질이나 모든 PC의 처리 속도를 보장하는 비교 검증은 아직 완료되지 않았습니다.

## 설치 및 실행

1. 이 저장소의 소스 또는 GitHub Actions의 `BallonsTranslator-Local-Windows-source` 파일을 다운로드하고, 쓰기 가능한 폴더에 압축을 풉니다. GitHub의 ZIP 안에 실행 ZIP이 있으면 안쪽 ZIP도 풀어야 합니다.
2. `launch_local.bat`를 실행합니다. 최초 실행은 인터넷이 필요하며, Python과 기존 앱·선택 모델의 필수 패키지를 설치합니다.
3. Ollama가 없으면 공식 설치 파일의 Windows 서명과 게시자를 확인한 뒤 설치 화면을 엽니다. 설치 화면을 완료합니다.
4. 프로그램의 준비 화면에서 이미지 처리 모델과 번역 모델을 각각 처음 한 번 다운로드합니다. 실행 환경 설치만 끝난 상태에서는 아직 번역을 시작할 수 없습니다. 번역 모델 태그는 `qwen3.5:9b-q4_K_M`이며 모델 자체의 다운로드는 약 6.6GB입니다. 전체 설치 공간은 Python, PyTorch, OCR·복원 모델, Ollama의 추가 공간이 필요합니다.
5. 필요한 항목의 준비 상태를 확인한 뒤 폴더를 열고 번역합니다.

Windows 10 22H2 이상, 64비트 x86 PC를 대상으로 합니다. Ollama의 GPU 지원과 요구 드라이버는 [공식 Windows 문서](https://docs.ollama.com/windows)를 따릅니다. 이미지 처리용 PyTorch는 기존 프로그램의 GPU 감지기로 설치 프로필을 선택합니다. 기본 로컬판은 이미지 검출·OCR·복원을 먼저 진행하고 해당 모델을 메모리에서 해제한 뒤 Ollama 번역을 진행하는 저메모리 경로를 사용합니다. 따라서 전체 페이지의 이미지 처리 진행률이 먼저 올라가고 번역이 나중에 시작되는 것은 정상입니다. 이 방식도 모델 자체의 메모리 요구를 없애지는 않으므로, RAM·VRAM 여유가 부족하면 느려지거나 모델 로딩이 실패할 수 있습니다.

수동으로 실행 환경만 준비할 때는 저장소 폴더의 PowerShell에서 다음 명령을 사용합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_local.ps1 -InstallOllama
```

## 최초 설치 오류 복구

Python 패키지 설치 중 `BackendUnavailable: Cannot import 'setuptools.build_meta'`가 발생하면 Windows 임베디드 Python이 별도의 pip 빌드 환경을 찾지 못한 경우일 수 있습니다. 수정된 실행기는 전용 Python 환경에 `setuptools`·`wheel`을 설치하고, Python 패키지 설치 시 빌드 격리를 비활성화합니다.

이미 설치에 실패했다면 수정된 소스의 `scripts/install_local.ps1` 및 `scripts/local_windows_helpers.ps1`을 적용한 뒤 `launch_local.bat`을 다시 실행하십시오. 완료 표식(`.ready`)이 생성되지 않은 환경에서는 패키지 설치를 다시 시도합니다. 기존 모델과 설정, 작업 이미지는 삭제하지 않습니다. 설치 완료 후 실제 번역이 정상 작동하는지는 별도 확인이 필요합니다.

## 저장 위치와 로컬 처리

- Python 실행 환경: 프로그램 폴더의 `local_runtime_win`
- 앱의 이미지 처리 모델: `data/models`
- 로컬판 설정: `config/hebi-local.json`
- Ollama 모델: 기본적으로 사용자 프로필의 `.ollama/models`; 이미 설정한 `OLLAMA_MODELS`가 있으면 해당 경로
- 실행 로그: 프로그램 폴더의 `logs`

기존 Python 환경, 모델, 설정을 자동으로 삭제하지 않습니다. 설치 실패 시 같은 명령으로 재시도할 수 있습니다. Python 실행 파일 없이 `local_runtime_win` 폴더만 남아 있으면 덮어쓰지 않고 안내합니다. 폴더를 백업하거나 다른 이름으로 옮긴 뒤 다시 시도하십시오.

실행기는 이 프로그램 전용 Ollama 서버를 `127.0.0.1:11435`에서 시작하고, 해당 자식 프로세스에 `OLLAMA_NO_CLOUD=1`을 적용합니다. 기존 Ollama 서버나 Windows의 사용자 환경 변수를 변경하지 않습니다. 다음 이미지 처리 단계가 시작되기 전에는 Ollama 번역 모델의 메모리 해제 응답을 기다립니다. 연속 번역 중에는 페이지마다 모델을 다시 로드하지 않습니다. 앱을 정상 종료하면 실행기가 자신이 시작한 서버만 종료합니다. 같은 포트를 이미 사용 중이면 기존 프로세스를 건드리지 않고 실행을 중단합니다. 강제 종료로 전용 서버가 남았을 때는 작업 관리자에서 해당 프로세스를 확인해야 합니다.

Hugging Face와 Transformers는 실행기에서 오프라인 로딩 설정을 사용하므로, 설치한 OCR을 불러올 때 누락된 파일을 몰래 온라인에서 가져오지 않습니다. 앱 준비 화면의 명시적인 모델 다운로드에는 인터넷을 사용합니다. 최초 준비와 업데이트 이후 네트워크를 차단한 실제 Windows PC에서 전체 번역을 완료하는 최종 검증은 별도로 필요합니다.

## 배포 형식과 검증

### 말풍선 분리와 문맥 번역

로컬판은 서로 다른 닫힌 말풍선의 경계가 분명하면 검출된 글줄을 합치지 않습니다. 한 말풍선 안의 여러 세로 글줄은 함께 처리하며, 경계가 열리거나 불분명하면 기존 글줄 간격·방향 판단을 사용합니다. 실제 컷과 말풍선을 완벽히 구분하는 기능은 아니므로 복잡하게 겹친 경계는 검수가 필요할 수 있습니다.

번역에는 각 대사의 위치·원문 방향과 같은 페이지 대사를 함께 전달합니다. 일부 말풍선만 다시 번역할 때도 주변 대사를 제한된 길이로 참고하며, 선택하지 않은 번역문은 수정하지 않습니다. 이전 페이지 문맥도 기존 길이 제한 안에서 사용합니다. 대사의 위치가 가깝다는 이유만으로 같은 인물이나 이어지는 문장이라고 단정하지 않도록 지시합니다.

준비 화면의 **이미지 문맥 자동 확인**은 기본으로 켜져 있습니다. 길쭉한 세로 대사나 가까이 붙은 대사는 같은 Qwen 모델이 축소한 원본 페이지 이미지도 참고합니다. 별도 모델은 설치하지 않습니다. 이미지로 OCR 원문을 임의로 바꾸거나, 서로 다른 말풍선의 번역을 한 영역에 몰아넣지 않도록 요청합니다. 메모리가 부족하거나 느리면 이 옵션을 끄고 텍스트 문맥만 사용할 수 있습니다. 설정은 다음 실행에도 유지됩니다.

이미지는 최대 긴 변 1,024픽셀로 전달하므로 작은 글씨를 다시 읽는 고해상도 OCR 기능을 대신하지 않습니다. 문맥이 너무 길면 참고 이력과 주변 대사부터 줄이고, 그래도 입력 한도를 넘으면 이미지 없이 대사·위치 문맥으로 전환한 사실과 페이지를 로그에 기록합니다. 번역할 원문 자체는 자르지 않습니다. 이미지 없이도 필수 입력이 제한을 넘으면 오류를 표시합니다. 실제 번역 정확도와 이미지 참고 시의 VRAM 사용량은 사용자 PC에서 확인해야 합니다.

### 한국어 조판과 확인 필요 항목

한국어 자동 조판은 어절과 명시적인 줄바꿈을 보존하고, 말풍선 안쪽의 여백을 고려해 글자 크기와 줄 배치를 조정합니다. 자동 배치가 어려운 긴 대사는 임의로 줄이거나 생략하지 않습니다. 해당 페이지를 **확인 필요**로 표시하고 자동 결과 이미지 저장을 중단합니다. 이전 결과 이미지가 있다면 그대로 보존합니다.

원래 글자 크기의 절반과 8pt 중 큰 값을 자동 축소의 하한으로 사용하며, 원래 글자가 그보다 작으면 더 줄이지 않습니다. 고정 글자 크기 설정도 유지합니다. 닫힌 경계가 없는 말풍선, 배경 위 대사, 회전된 대사는 자동으로 적합성을 확정하기 어려워 검수 대상으로 남을 수 있습니다.

확인 필요 항목은 편집기에서 안내된 페이지를 열어 번역문 길이·글자 크기·텍스트 위치를 확인한 뒤 재시도하십시오. 번역문과 프로젝트는 보존되며, 재시도는 해당 배치가 적합한지 다시 확인합니다. 저장이 거부되면 페이지 이동과 종료도 멈춰 편집 내용을 유지합니다. 직접 검수한 페이지는 편집기의 수동 저장으로 내보낼 수 있습니다. 수동 저장은 자동 검수 통과를 뜻하지 않으므로 확인 필요 표시는 유지됩니다.

현재 기본 모델은 Qwen3.5 9B Q4_K_M입니다. RTX 4070 SUPER 12GB의 실측 성능이나 다른 모델과의 일본어→한국어 만화 번역 품질 비교는 완료되지 않았습니다. Hy-MT2 7B 같은 비교 후보를 검토했지만, 실제 이미지와 GPU에서 검증하기 전에는 기본 모델이나 설치 항목을 추가하지 않습니다.

### 사용자가 선택한 영역 재작업

1. 편집기에서 **도구 → 영역 재작업** 또는 `Ctrl+Shift+R`을 선택합니다. 그림 도구의 **영역 재작업** 버튼으로도 시작할 수 있습니다.
2. 이미지에서 잘못 처리된 말풍선 전체가 들어가도록 사각형을 드래그합니다.
3. **선택 영역 재작업**을 누릅니다. 드래그만으로 실행하지 않으며, **선택 취소**로 범위를 취소할 수 있습니다.
4. 원본 이미지에서 선택 범위를 다시 검출·인식하고, 배경 복원과 문맥 번역을 거쳐 결과를 한 번에 적용합니다. 영역 안에서 직접 수정했던 대사는 새 결과로 바뀌며, 겹쳐 칠한 브러시·도형도 해당 범위만 지워집니다. 필요한 범위만 선택하십시오.
5. 완료 후 대사 편집 화면에서 결과를 확인합니다. `Ctrl+Z` 한 번으로 해당 재작업의 대사·배경·그림 편집을 함께 되돌릴 수 있습니다. 확인한 결과는 기존 저장 기능으로 저장합니다.

선택 경계에 기존 말풍선이 걸치면 범위를 넓히도록 안내합니다. 선택하지 않은 대사·이미지는 보존하며, 실패·중지·페이지 변경·편집 변경이 감지되면 이전 결과를 유지합니다. 새 대사를 찾지 못했거나 결과가 선택 범위에 들어가지 않는 경우에도 기존 결과를 지우지 않습니다. 번역 중에는 다른 일괄 작업을 시작할 수 없습니다.

배경 복원에는 기존 LaMa를 사용하며 추가 모델을 설치하지 않습니다. 선택 영역 주변의 그림을 참고하되 실제 픽셀 반영은 영역 안의 제거 마스크로 제한합니다. 이전에 지웠던 마스크도 포함하므로 해당 범위의 복원을 원본에서 다시 시도할 수 있습니다. 일반 자동 처리에서는 단색 말풍선을 색으로 채우는 빠른 경로가 있지만, 영역 재작업은 LaMa 복원을 사용합니다. 가려져 있던 원래 그림을 정확히 되찾는 기능은 아니며 얼굴·복잡한 선·망점은 검수가 필요합니다.

대사를 바꾸지 않고 잔여 글자나 배경만 손보려면 기존 그림 편집기의 복원 브러시를 사용하십시오. 이 도구는 사용자가 표시한 부분을 주변 그림으로 채우며 한국어 대사를 다시 번역하지 않습니다.

### 패키지 검사

현재 배포 파일은 **소스와 설치·실행 스크립트가 포함된 ZIP**입니다. Python·Ollama·모델이 모두 포함된 단독 EXE나 오프라인 완성 배포본은 아닙니다. GitHub 비공개 저장소를 다시 복제하지 않으므로 다운로드한 소스가 있으면 실행 준비를 진행할 수 있습니다.

개발자가 패키지를 만들 때는 추가할 소스를 Git에 먼저 등록하고 다음 명령을 실행합니다. Git에 등록된 파일의 현재 작업 내용을 사용하며, 등록하지 않은 개인 파일, 런타임, 모델, 개인 설정, 일반적인 인증 파일은 제외합니다. 기존 ZIP을 덮어쓰지 않습니다.

```powershell
python scripts/build_local_package.py --output release/BallonsTranslator-Local-Windows-source.zip
```

GitHub Actions의 **Local Windows bootstrap package** 작업은 Windows에서 PowerShell 구문·환경·실패 전파 검사, Python 컴파일, 로컬판 관련 회귀 테스트와 ZIP 생성을 수행합니다. 회귀 검사는 Qt의 전역 객체가 서로 다른 테스트 파일에 영향을 주지 않도록 파일마다 새 Python 프로세스에서 실행하며, 실패·충돌·시간 초과가 발생하면 패키지를 만들지 않습니다. 테스트를 통과해야 다운로드용 artifact가 생성됩니다. 모델 다운로드나 GPU 추론, 실제 만화 번역은 CI에서 수행하지 않습니다. GitHub Actions가 아직 실행되지 않았거나 실패한 경우 Windows 검증이 완료된 것으로 볼 수 없습니다.

CI의 회귀 범위는 `scripts/run_local_regressions.py`에 명시되어 있습니다. 로컬 설치 상태, Ollama 요청, 작업 화면, 한국어 조판·넘침 검수, 이어서 처리·저메모리 경로, 번역 응답 형식, 파이프라인 오류, 실행 창, 이미지 저장·읽기, 재실행과 의존성 선택을 검사합니다. 한국어 조판과 저장 경로는 Qt 5에서도 검사합니다. 기존 전체 테스트를 모두 실행하는 검증은 아니며, 원본의 문맥 기본값 불일치(테스트는 4,096, 현재 기본값은 10,000) 같은 별도 이슈는 이 검증으로 해결되었다고 볼 수 없습니다. CI의 `openai`·`PyQt5` 패키지는 회귀 테스트용이며 로컬판 설치 요구사항에는 추가하지 않습니다.

원본 GPL 라이선스와 소스는 패키지에 포함됩니다. 모델 이용 조건은 각 배포처를 따릅니다.
