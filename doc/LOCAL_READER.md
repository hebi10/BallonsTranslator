# 결과 뷰어·이미지 합치기

로컬 작업 화면에서 폴더를 선택한 뒤 **뷰어로 읽기** 또는 **이미지 합치기 · 폰용 저장**을 선택합니다. 저장된 결과 이미지가 있어야 합니다. 두 기능은 모델을 불러오거나 네트워크를 사용하지 않습니다.

## 읽기
왼쪽 목록과 페이지 번호로 이동합니다. 위쪽에서 세로 이어 읽기/한 장 보기, 화면 폭/페이지 전체 맞춤, 확대 비율을 선택합니다. PgUp/PgDn으로 페이지를 이동하고 F11로 전체 화면을 전환합니다. 전체 화면에서 Esc는 일반 창으로 복귀하고, 일반 창에서 Esc는 닫기입니다. 마지막으로 읽은 페이지와 위치는 로컬 설정 옆 `local_reader.json`에 저장합니다.

**이 페이지 편집**은 기존 편집기의 해당 원본 페이지로 연결합니다. 뷰어는 저장된 결과만 보여 주므로, 편집기에서 수정·저장한 뒤 다시 열어야 갱신됩니다. 저장되지 않은 수정, 재저장·검수 필요 상태, 누락된 결과는 숨기지 않고 표시합니다. 페이지 중간의 결과가 없어도 앞뒤를 이어 붙인 것처럼 누락시키지 않습니다.

## 합치기
1. 왼쪽에서 포함할 페이지를 체크하고 위로/아래로 또는 순서 반대로 버튼으로 순서를 정합니다.
2. 세로는 폭을, 가로는 높이를 맞춥니다. 종횡비를 유지하고 작은 원본을 확대하지 않습니다. 가로 순서 변경은 그림 자체를 뒤집지 않습니다.
3. 기본 폰용 설정은 세로, 폭 1080px, 간격 없음, 12000px 단위 분할, PNG입니다. PNG/JPEG를 선택할 수 있으며 JPEG 품질의 기본값은 92입니다.
4. 분할을 해제하면 선택한 페이지를 한 장으로 합칩니다. 분할은 페이지 사이에서만 일어나며, 단일 페이지가 설정 길이를 넘으면 기준 크기를 줄이거나 길이를 늘리라는 안내가 표시됩니다.
5. 파일별 미리보기와 실제 픽셀 크기를 확인합니다. 경고가 있으면 저장된 결과 사용 확인란을 체크해야 내보낼 수 있습니다. 없는/손상된 결과는 수정하거나 사용자가 직접 선택에서 제외해야 합니다.
6. **별도 폴더로 저장**을 누릅니다. 지정한 저장 위치 아래 새 `읽기용_날짜_식별자` 폴더에 001.png/002.png 또는 JPEG가 저장됩니다. 원본·프로젝트·기존 결과를 덮어쓰지 않습니다.

취소는 현재 이미지 처리가 끝난 뒤 적용될 수 있습니다. 전체 파일이 완료되기 전에는 새 결과 폴더를 공개하지 않으며, 실패·취소 시 이번 작업의 임시 결과만 정리합니다. 미리보기 이후 파일 내용이 바뀌면 창을 다시 열어야 합니다.

## 보호 기준과 범위
이미지당 출력 3200만 픽셀, 한 변 60000px, 입력 4000만 픽셀 제한을 둡니다. 큰 파일은 기준 크기 조정이나 분할을 사용하세요. 이 수치는 앱 메모리 보호 기준이며 모든 휴대폰 갤러리의 호환성을 뜻하지 않습니다. 폰에는 내보낸 이미지 파일을 옮겨서 봅니다. 전용 모바일 앱, 동기화, CBZ 내보내기는 포함하지 않습니다.

테스트는 합성 이미지와 Qt offscreen으로 실행합니다. 실제 번역 품질·Windows 실기기 GPU·휴대폰 갤러리 성능을 대신하지 않습니다.
