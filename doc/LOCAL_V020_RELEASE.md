# Windows 로컬 번역판 v0.2.0

영어·일본어 자동 인식과 검수 흐름을 통합한 Windows 테스트 배포입니다.

## 변경 내용

- 새 폴더는 영어·일본어 자동 인식, 혼합 페이지는 말풍선별 OCR 선택
- 원문 언어와 읽는 방향 분리, 페이지·말풍선 언어 수동 지정
- 작품별 이름·용어집·말투 메모 저장 및 명시적 재사용
- 확인 필요한 대사 목록과 해당 위치 이동, 선택 영역 재작업 연결
- 원본 작업물을 보존하는 별도 폴더에서 이미지 한 장 전체 시험
- 원본·결과 뷰어, 이미지 합치기·휴대폰 분할 저장 통합
- 영어 지원과 Windows 임베디드 Python 설치 수정 포함

## 사용 순서

1. `BallonsTranslator-Local-Windows-source.zip`을 풀고 `launch_local.bat`을 실행합니다.
2. 원문 언어를 **자동 · 영어/일본어**로 두고 **상태 확인 → OCR·복원 모델 준비**를 실행합니다.
3. 기존 번역 모델은 재사용합니다. 처음 설치한 경우에만 번역 모델을 다운로드합니다.
4. 폴더 추가 후 **선택 이미지 1장 시험**으로 결과를 확인합니다.
5. **번역 시작·이어서 실행** 후 **확인 필요 모아보기**로 문제 대사를 수정합니다.

기존 설치 업데이트는 프로그램을 종료한 뒤 소스를 갱신합니다. 개인 설정·모델·실행 환경·만화 폴더는 삭제하지 마십시오. 이전 기능별 업데이트 ZIP을 이 통합판 위에 다시 덮어쓰지 마십시오.

## 배포·검증 범위

- Windows용 소스·설치 런처 ZIP입니다. APK, 단독 EXE, 모델 가중치는 포함하지 않습니다.
- 번역은 로컬 Ollama의 Qwen3.5 9B Q4_K_M을 사용합니다. 최초 설치·모델 다운로드에는 인터넷이 필요합니다.
- 자동 감지 지원 범위는 영어·일본어입니다. 짧은 효과음·한자만 있는 대사·복잡한 그림은 검수가 필요합니다.
- Windows 설치 스크립트·패키지 경계·회귀 검사와 Qt5/Qt6 검증을 통과한 소스만 배포합니다.
- 실제 사용자 PC의 GPU 속도, 실사용 번역 정확도, 복잡한 그림의 복원 품질은 자동 테스트로 검증하지 않았습니다.
