## 아직 검증하지 않은 범위

- 실제 Windows PowerShell 설치 실행, 드라이버 및 GPU 호환성. GitHub Actions가 성공하면 Windows 스크립트·패키지 검사는 추가로 확인할 수 있으나 실제 GPU 검증은 아닙니다.
- 실제 Qwen3.5 / manga_ocr / CTD / LaMa 가중치 다운로드·로드 및 만화 이미지의 번역 품질·속도·메모리 사용량.
- 최초 준비 이후 인터넷을 차단한 Windows PC에서 전체 번역을 완료하는 검사.

실제 모델 가중치는 이번 개발 환경에 다운로드하지 않았습니다. 앱의 번역 실행 테스트는 설치한 PC에서 실제 한국어 응답을 확인합니다. 모델의 6.6GB 다운로드 크기는 RAM/VRAM 최소 요구량을 뜻하지 않습니다.

## 원본에서 확인한 한계

- 전체 pytest를 한 프로세스로 실행하면 원본에서도 Qt 네이티브 종료 오류가 재현됩니다. 로컬판 CI는 관련 테스트를 파일별 새 프로세스에서 실행하며 실패를 무시하지 않습니다.
- 원본 `test_proj_imgtrans_translation_context`에는 기대 기본값 4,096과 현재 기본값 10,000의 불일치가 있습니다. 해당 파일은 로컬판 CI 범위에서 제외되어 있으며 전체 원본 테스트의 통과를 주장하지 않습니다.
- 정상 일시정지는 워커 종료 후 저장합니다. 강제 종료 시 마지막 확정 저장 이후 현재 페이지의 작업은 다시 실행될 수 있습니다. 단계마다 완전한 디스크 트랜잭션을 보장하지 않습니다.
