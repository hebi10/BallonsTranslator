# 로컬 결과 뷰어·이미지 내보내기

승인 범위: PC 전용 뷰어, 세로·가로 합치기, 폰용 페이지 경계 분할. 기존 로컬판·모델·원본 편집 동작 유지. 모바일 앱과 CBZ는 이번 범위에서 제외한다.

## 사용자 흐름
로컬 작업 목록에서 폴더 선택 → 뷰어로 읽기 / 이미지 합치기. 읽기 화면은 페이지 목록, 연속 스크롤·한 장 보기, 폭·전체 맞춤, 확대, 이전·다음, 이어 읽기, 전체 화면, 해당 페이지 편집 연결을 제공한다. 합치기 화면은 포함 페이지와 순서, 방향, 기준 크기, 간격, PNG/JPEG, 분할 길이, 파일별 미리보기, 별도 저장 위치를 제공한다.

## 안전·성능
- 모델·네트워크 호출 없이 저장된 결과만 읽는다. 결과가 없는 페이지를 숨기거나 원본으로 대체하지 않는다.
- 프로젝트 순서를 우선한다. 저장되지 않은 수정, 검수 필요, 재저장 상태, 중복 결과명은 명시한다. 경고가 있는 결과 내보내기는 별도 확인이 필요하다.
- 원본·프로젝트·기존 결과를 수정하지 않는다. 매 내보내기는 새 하위 폴더를 사용한다. 실패·취소 시 이 작업의 임시 폴더만 제거한다.
- 헤더 읽기, 이미지 디코딩, 미리보기, 파일 저장은 워커에서 수행한다. 읽기 화면은 현재 위치 주변 이미지만 캐시한다. 실행 중인 스레드를 강제로 종료하지 않는다.
- 기본 폰용 폭은 1080px, 분할 길이는 12000px. 작은 원본은 확대하지 않는다. 분할은 페이지 사이에서만 수행하며, 단일 페이지가 한도를 넘으면 안내한다.
- 내보내기 이미지당 3200만 픽셀·한 변 60000px 상한, 입력 이미지당 4000만 픽셀 상한을 둔다. 이는 앱 보호 기준이지 모든 휴대폰의 호환성 보장이 아니다.
- 새 라이브러리 없음. 기존 qtpy·PyQt 및 Pillow와 표준 라이브러리를 사용한다. 기존 테마를 따르고 과도한 장식 없이 한글 버튼과 상태·오류 안내를 제공한다.

## 검증
순서·배율·EXIF·누락·손상·분할 경계·수평 순서·PNG/JPEG·취소·파일 변경·원본 보존을 단위 검사한다. Qt5/Qt6 offscreen에서 읽기·내보내기 화면, 비동기 종료, 편집 연결, 좁은 화면의 배치를 검사한다. 실제 Windows 및 폰의 체감 성능은 별도 검증 범위다.
