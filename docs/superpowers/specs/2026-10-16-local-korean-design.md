# 해비 로컬 만화 번역기

승인 범위: 기존 Python/Qt 앱을 유지하고 일본어→한국어 로컬 번역, 설치 진단, 일괄 작업 복구, 간편 화면, Windows 실행 패키지를 순서대로 제공한다.

## 구성

- 검출 CTD, OCR manga_ocr, 복원 LaMa large 512px, 번역 Ollama Qwen3.5 9B Q4_K_M 하나를 노출한다.
- 정확한 번역 모델 태그는 `qwen3.5:9b-q4_K_M`이다. 공식 Ollama에서 2026-10-16 확인한 다운로드 용량은 약 6.6GB다. 보편적인 최고 품질을 주장하지 않는다.
- 별도 Windows Ollama 프로세스는 `127.0.0.1:11435`, `OLLAMA_NO_CLOUD=1`을 사용한다. 기존 사용자 서버/환경 설정을 바꾸지 않는다.
- 기존 LLMTranslator의 용어집, 번역 이력, 구조화된 응답 검증을 재사용하고 native Ollama API의 think=false를 적용한다.
- 문맥은 8192, 이전 번역 예산 2048, 출력 2048 토큰부터 시작한다. 실행 검사로 모델 로드와 JSON 응답 성공을 확인한다.

## 데이터와 화면

- 새 로컬 설정 파일 `config/hebi-local.json`을 사용한다. 기존 설정·다운로드 모델·프로젝트를 삭제하지 않는다. 기존 엔진 구현은 호환성을 위해 보존하지만 로컬 앱에서 선택하거나 설치할 수 없다.
- 초기 화면은 모델 설치/연결/실행 준비 상태, 설치 및 재검사 버튼을 제공한다. 추론과 다운로드는 Qt 메인 스레드 밖에서 실행한다.
- 파일 목록, 폴더 큐, 원본/결과 확인, 기존 캔버스 대사 편집, 결과 저장 흐름을 연결한다. 기존 테마 사용, 불필요한 장식 없음.
- Continue는 완료 단계를 재사용하며 수동 수정 결과를 지우지 않는다. 실패는 완료로 표시하지 않으며 실패 단계가 남아야 한다.
- 페이지 저장과 정상 중단 후 저장을 검증한다. 강제 종료에서 마지막 확정 저장 이후 처리 중인 단계는 재실행할 수 있다. 완전한 트랜잭션형 단계별 내구성이 구현되지 않았다면 보장하지 않는다.
- 여러 폴더의 큐는 디스크에 저장하고, 워커와 이미지 저장이 끝난 후 다음 폴더를 연다.

## 검증 및 배포

- 로컬 HTTP 가짜 서버로 모델 조회·다운로드·구조화 번역·취소·실패·리다이렉트 차단 검증.
- Qt offscreen 화면 생성 및 프로젝트 재개 회귀 테스트.
- 전체 테스트를 실행하되 기존 환경/테스트 실패는 기록한다.
- Windows 소스+설치 런처 ZIP 제공. Windows에서 직접 검증하지 못한 동작과 실제 모델 번역 품질은 완료로 표시하지 않는다.
- 소스 및 변경 이력을 사용자 GitHub 작업 브랜치와 PR에 보관한다. 기본 브랜치 병합은 별개다.
